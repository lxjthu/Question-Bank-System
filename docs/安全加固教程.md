# 服务器安全加固教程

> 适用环境：阿里云轻量服务器，CentOS/RHEL 系，已完成基本部署。

---

## 一、SSH 密钥登录（替代密码登录）

### 1.1 为什么要用密钥登录

密码登录容易被暴力破解，互联网上有大量自动化脚本持续扫描 22 端口并尝试常见密码。密钥登录本质上是一对加密密钥：
- **私钥**：保存在本机，相当于钥匙，绝不外传
- **公钥**：上传到服务器，相当于锁

只有持有私钥的机器才能登录，无法被暴力破解。

### 1.2 在本机生成密钥对（Windows PowerShell）

```powershell
ssh-keygen -t ed25519 -C "备注名，如 my-pc"
```

提示说明：
- `Enter file in which to save the key`：直接回车，使用默认路径 `C:\Users\用户名\.ssh\id_ed25519`
- `Enter passphrase`：直接回车（不设密码短语，方便日常使用）

生成后会得到两个文件：
- `C:\Users\用户名\.ssh\id_ed25519`：**私钥**（绝对不要泄露）
- `C:\Users\用户名\.ssh\id_ed25519.pub`：**公钥**（可以公开）

### 1.3 将公钥上传到服务器

```powershell
type $env:USERPROFILE\.ssh\id_ed25519.pub | ssh root@服务器IP "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys"
```

这一步会提示输入密码，输入一次即可。

### 1.4 验证密钥登录是否成功

```powershell
ssh root@服务器IP
```

**不需要输入密码就直接进入服务器**，说明密钥登录配置成功。

> ⚠️ **重要**：必须先验证密钥登录成功，再执行下一步禁用密码登录。否则会被锁在外面。

### 1.5 禁用密码登录

在服务器上执行：

```bash
sed -i 's/^#\?PasswordAuthentication.*/PasswordAuthentication no/' /etc/ssh/sshd_config
systemctl restart sshd
```

### 1.6 验证禁用是否生效

**不要关闭当前 SSH 窗口**，新开一个 PowerShell 窗口执行：

```powershell
ssh root@服务器IP
```

仍然能直接登录（无需密码）说明一切正常。

## 二、SSH 密钥换电脑转移

私钥文件保存在本机 `C:\Users\用户名\.ssh\id_ed25519`，换电脑时将其复制到新电脑的相同路径即可。

**转移步骤：**

1. 用 U 盘将 `id_ed25519`（私钥）复制到新电脑的 `C:\Users\新用户名\.ssh\id_ed25519`
2. 如果 `.ssh` 目录不存在，先手动创建
3. 直接执行 `ssh root@服务器IP`，无需任何其他配置

**安全注意事项：**
- 私钥相当于钥匙，不要通过邮件、微信、QQ 传输
- U 盘传完后从 U 盘删除原文件
- 不同电脑建议生成各自独立的密钥对，分别上传公钥到服务器（更安全）

**多台电脑的情况：**

每台电脑生成自己的密钥对，将各自的公钥追加到服务器的 `authorized_keys`：

```bash
# 在服务器上查看已授权的公钥
cat ~/.ssh/authorized_keys

# 追加新公钥（在新电脑上执行）
type $env:USERPROFILE\.ssh\id_ed25519.pub | ssh root@服务器IP "cat >> ~/.ssh/authorized_keys"
```

## 三、Nginx 登录限速（防暴力破解）

### 3.1 为什么要限速

即使有密钥登录保护 SSH，Web 应用的登录接口（`/api/auth/login`）仍然可能被暴力破解。限速策略限制同一 IP 每分钟只能尝试 5 次登录，超过则返回 429 错误。

### 3.2 配置文件

完整的 Nginx 配置文件位于 `/etc/nginx/conf.d/exam-system-online.conf`：

```nginx
limit_req_zone $binary_remote_addr zone=login:10m rate=5r/m;

server {
    listen 80;
    server_name 服务器IP或域名;

    client_max_body_size 20M;

    server_tokens off;   # 隐藏 Nginx 版本号，减少信息泄露

    location /static/ {
        alias /root/exam-system-online/app/static/;
        expires 7d;
    }

    location /uploads/images/ {
        alias /root/exam-system-online/uploads/images/;
        expires 7d;
    }

    # 登录接口：限制同一 IP 每分钟最多 5 次，允许突发 3 次
    location /api/auth/login {
        limit_req zone=login burst=3 nodelay;
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 180s;
    }

    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 180s;
    }
}
```

参数说明：
| 参数 | 含义 |
|------|------|
| `zone=login:10m` | 创建名为 login 的内存区，存储 IP 状态，10MB 约可跟踪 16 万个 IP |
| `rate=5r/m` | 每个 IP 每分钟最多 5 次请求 |
| `burst=3` | 允许短时突发 3 次（正常用户快速刷新不会被误封） |
| `server_tokens off` | 隐藏响应头中的 Nginx 版本号 |

### 3.3 修改配置后重载

```bash
nginx -t                  # 检查语法
systemctl reload nginx    # 不停服重载
```

## 四、阿里云安全组配置

安全组是云服务器的防火墙，控制哪些端口对外开放。

**建议只开放：**

| 端口 | 协议 | 用途 |
|------|------|------|
| 80 | TCP | HTTP 网站访问 |
| 443 | TCP | HTTPS（有域名时使用） |
| 22 | TCP | SSH 远程管理（可改为非标准端口） |

**操作路径：**
阿里云控制台 → 轻量应用服务器 → 防火墙 → 添加/删除规则

## 五、HTTPS 配置（需要域名）

如果有域名，可以用 Let's Encrypt 免费证书开启 HTTPS，数据传输全程加密。

```bash
# 安装 certbot
yum install -y certbot python3-certbot-nginx

# 自动申请证书并配置 Nginx
certbot --nginx -d 你的域名

# 证书有效期 90 天，设置自动续期
echo "0 0 1 * * certbot renew --quiet" >> /etc/crontab
```
