# 试卷生成系统（线上版）部署教程

> 适用环境：阿里云轻量服务器，CentOS/RHEL 系，已有旧版 Flask 应用在跑。

---

## 一、部署前准备

### 1.1 确认旧版状态

登录服务器，检查旧版服务和端口占用：

```bash
# 查看旧版服务名
systemctl list-units --type=service | grep -i exam

# 查看旧版服务配置
systemctl cat exam-system.service

# 查看 5000 端口是否被占用
ss -tlnp | grep 5000
```

### 1.2 停止旧版（如果不再需要）

```bash
systemctl stop exam-system.service
systemctl disable exam-system.service
```

确认端口已释放：

```bash
ss -tlnp | grep 5000
# 无输出则表示端口已空闲
```

## 二、打包代码（本机操作）

在本机项目根目录，用 Python 脚本打包，**排除敏感文件和无用文件**：

```python
import zipfile, pathlib

src = pathlib.Path(r'D:/code/试卷/试卷生成-online')
out = pathlib.Path(r'D:/code/试卷/exam-system-online.zip')

EXCLUDE_DIRS  = {'venv', '__pycache__', 'exports', 'temp', 'rag_uploads', 'uploads', 'plans', 'docs', '.git'}
EXCLUDE_FILES = {'.env', 'exam_system.db', 'ds_knowledge.db', 'server.log', 'start.bat',
                 '管理员密码不要打包.txt', 'CLAUDE.md', 'PROGRESS.md'}

count = 0
with zipfile.ZipFile(out, 'w', zipfile.ZIP_DEFLATED) as zf:
    for path in src.rglob('*'):
        if any(part in EXCLUDE_DIRS for part in path.parts):
            continue
        if path.name in EXCLUDE_FILES:
            continue
        if path.suffix == '.pyc':
            continue
        if path.is_file():
            arcname = 'exam-system-online/' + path.relative_to(src).as_posix()
            zf.write(path, arcname)
            count += 1

print('打包完成，共 %d 个文件，大小 %.1f KB' % (count, out.stat().st_size / 1024))
```

**排除的内容说明：**

| 排除项 | 原因 |
|--------|------|
| `.env` | 含管理员密码和 API Key，绝对不能打包 |
| `venv/` | 体积大，服务器会重新安装 |
| `*.db` | 数据库文件，属于运行时数据 |
| `exports/` `temp/` `uploads/` `rag_uploads/` | 运行时产生的目录 |
| `start.bat` | Windows 专用启动脚本 |

## 四、服务器端部署

### 4.1 解压

```bash
cd /root
unzip exam-system-online.zip
ls exam-system-online/   # 确认文件存在
```

### 4.2 确认 Python 版本

本项目使用了 Python 3.10+ 语法（如 `str | None` 类型注解），**必须使用 Python 3.11**。

```bash
which python3.11
python3.11 --version
```

### 4.3 创建虚拟环境并安装依赖

```bash
cd /root/exam-system-online
python3.11 -m venv venv
source venv/bin/activate
python --version          # 确认显示 3.11
pip install -r requirements.txt
```

### 4.4 配置 .env

```bash
# 生成随机 SECRET_KEY
python -c "import secrets; print(secrets.token_hex(32))"

# 创建 .env 文件（将下面的值替换为实际内容）
SECRET=$(python -c "import secrets; print(secrets.token_hex(32))")
echo "SECRET_KEY=${SECRET}" > .env
echo "ADMIN_PASSWORD=你的管理员密码" >> .env
echo "FLASK_ENV=production" >> .env

# 确认内容正确
cat .env
```

`.env` 最终内容示例：

```
SECRET_KEY=a3f8c2d1e4b7a9f0c2d1e4b7a9f0c2d1e4b7a9f0c2d1e4b7a9f0c2d1e4b7a9f0
ADMIN_PASSWORD=your_secure_password
FLASK_ENV=production
```

> **注意**：`FERNET_KEY` 可留空，系统会自动从 `SECRET_KEY` 派生用于 API Key 加密。

### 4.5 测试应用能否正常初始化

```bash
python -c "from app.factory import create_app; app = create_app('production'); print('OK')"
```

输出 `OK` 则继续，有报错需先排查。

## 五、配置 systemd 服务

```bash
# 复制 service 文件
cp /root/exam-system-online/exam-system-online.service /etc/systemd/system/

# 创建日志目录
mkdir -p /var/log/exam-system-online

# 重载 systemd 并启动服务
systemctl daemon-reload
systemctl enable exam-system-online
systemctl start exam-system-online
systemctl status exam-system-online
```

**正常状态输出示例：**

```
● exam-system-online.service - Exam System Online (Gunicorn)
   Active: active (running) since ...
 Main PID: 56785 (gunicorn)
           ├─56785 gunicorn --workers 5 --bind 127.0.0.1:5000 ...
           ├─56801 gunicorn worker ...
           ...（5个 worker 进程）
```

## 六、安装并配置 Nginx

### 6.1 安装 Nginx（如未安装）

```bash
yum install -y nginx
systemctl enable nginx
systemctl start nginx
```

### 6.2 配置反向代理

```bash
# 获取服务器公网 IP
curl -s ifconfig.me

# 复制 nginx 配置并替换 IP/域名
cp /root/exam-system-online/nginx.conf /etc/nginx/conf.d/exam-system-online.conf
sed -i 's/your-domain.com/你的服务器IP或域名/' /etc/nginx/conf.d/exam-system-online.conf

# 测试配置语法
nginx -t

# 重载 Nginx
systemctl reload nginx
```

## 九、目录结构说明

```
/root/exam-system-online/
├── app/                  # 应用代码
├── venv/                 # Python 虚拟环境（服务器本地生成）
├── uploads/              # 用户上传图片（运行时生成）
├── exports/              # 导出文件临时目录（运行时生成）
├── .env                  # 敏感配置（服务器本地创建，不入版本库）
├── exam_system.db        # SQLite 数据库（运行时生成）
├── requirements.txt      # Python 依赖
├── wsgi.py               # Gunicorn 入口
├── nginx.conf            # Nginx 配置模板
└── exam-system-online.service  # systemd 服务文件
```
